# 관극로그 : 공연 관람 가계부

같은 공연을 여러 번 보면 티켓값, 할인, 쿠폰, 양도, MD 구매 때문에 매번 쓴 돈이 달라져서
실제로 얼마를 썼는지 알기 어렵습니다.
**관극로그**는 공연과 관람 기록을 등록하면 한 번 볼 때마다 실제로 쓴 돈(순지출)을 자동으로 계산하고,
월별 / 공연별 통계와 순위를 보여주는 콘솔(CLI) 프로그램입니다.

- 공연 등록 · 수정 · 삭제, 공연마다 관람 기록 여러 개 관리
- 할인율, 쿠폰 여러 장, 예매 수수료, 양도, MD 구매를 한 번에 계산
- 월별 지출 통계, 공연별 지출 분석(회당 평균), 공연별 순위
- 공연명 / 공연장 / 캐스팅 검색
- 입력한 내용은 바로 `data.json` 파일에 저장되어 프로그램을 껐다 켜도 남아 있음

## 5. 기능별 사용법

### 5.1 공연 관리 (FR-01)

- 공연 관리 화면 위쪽에 등록된 공연 목록(ID, 공연명, 종류, 공연장, 관람 횟수, 순지출)이 항상 보입니다.
- **등록** : 공연명(필수), 공연 종류, 공연장을 입력합니다. ID 는 `P1`, `P2` ... 순서로 자동으로 붙습니다.
- **수정** : 공연 ID 를 고르고 바꿀 항목만 입력합니다. **Enter 만 누르면 원래 값이 그대로 남습니다.**
- **삭제** : 공연 ID 를 고르면 지울 공연 정보를 한 번 더 보여주고 `정말 삭제하시겠습니까? (y/n)` 를 물어봅니다.
  `y` 를 입력해야만 지워지며, **그 공연의 관람 기록도 모두 같이 지워집니다.**

### 5.2 관람 기록 관리 (FR-01, FR-02)

먼저 관람 기록을 관리할 공연의 ID 를 입력합니다.

- **추가** : 관람일, 좌석, 캐스팅, 지출 정보를 입력하면 계산 결과를 보여주고 `저장하시겠습니까? (y/n)` 를 물어봅니다.
  관람 기록 ID 는 `V1`, `V2` ... 로 붙고, **공연이 달라도 번호가 겹치지 않습니다.**
- **상세 보기** : 관람 기록 하나의 지출 계산 과정을 전부 보여줍니다.
  목록 표에서 칸보다 길어서 `..` 으로 잘린 캐스팅도 여기서는 전부 나옵니다.
- **수정** : Enter 만 누르면 원래 값을 유지합니다. 지출 정보는 `지출 정보도 수정하시겠습니까? (y/n)` 에서 `y` 를 골랐을 때만 다시 입력합니다.
  쿠폰과 MD 는 지금 등록된 목록을 보여주고 다시 입력할지 물어봅니다.
- **삭제** : 지울 기록의 내용을 한 번 더 보여주고 `(y/n)` 로 확인합니다.

#### 거래 유형별로 입력하는 항목

| 거래 유형 | 입력하는 것 | 실제 구매금액 |
|---|---|---|
| 1. 직접구매 | 정가, 할인명, 할인율, 쿠폰, 예매 수수료, 예매처, MD | 계산식으로 계산 |
| 2. 양도받음 | **양도자에게 지급한 금액**, 예매처, MD (정가·할인·쿠폰·수수료는 묻지 않음) | 지급한 금액 그대로 |
| 3. 양도함 | 직접구매 항목 + **티켓 양도 금액(받은 돈)** | 계산식으로 계산, 순지출에서 양도 금액을 뺌 |

### 5.3 월별 지출 통계 (FR-03)

연도와 월을 입력하면 모든 공연에서 그 달에 본 관람 기록만 골라서 보여줍니다.

- 그 달의 관람 목록 (관람일 순서) : 관람일, 공연명, 티켓 지출, MD, 순지출
- 합계 표 : 관람 횟수, 총 티켓 지출, 총 MD 지출, 총 순지출
- 그 달에 본 공연이 없으면 `2026년 3월의 관람 기록이 없습니다.` 라고 안내하고 돌아갑니다.

### 5.4 공연별 지출 분석 (FR-04)

공연 ID 를 고르면 그 공연의 관람 기록 전체와 누적 통계(관람 횟수, 총 티켓 지출, 총 MD 지출, 총 순지출)를 보여주고,
**회당 평균 지출(총 순지출 ÷ 관람 횟수)** 을 계산합니다.
관람 기록이 하나도 없는 공연은 0 으로 나눌 수 없어서 평균 대신 안내 문구를 보여줍니다.

### 5.5 공연별 순위 (FR-05)

공연마다 총 순지출을 구해서 **큰 순서대로** 순위, ID, 공연명, 총 순지출, 관람 횟수를 보여줍니다.

- 관람 기록이 없는 공연은 순위에 넣지 않습니다.
- 총 순지출이 같으면 같은 순위입니다.

### 5.6 검색 (FR-06)

검색 기준(1. 공연명 / 2. 공연장 / 3. 캐스팅)을 고르고 검색어를 입력합니다.

- **대소문자를 구분하지 않고**, 검색어가 **포함**되기만 하면 찾습니다. (예: `cosmos` 로 `XX : COSMOS` 검색)
- 공연명 · 공연장 검색은 찾은 공연의 관람 기록을 전부 보여줍니다.
- 캐스팅 검색은 **그 배우가 나온 관람 기록만** 보여줍니다.
- 찾은 게 없으면 `검색 결과가 없습니다.` 라고 안내합니다.

## 7. 계산식

### 관람 1회

```
실제 구매금액 = 정가 - (정가 × 할인율) - 쿠폰 합계 + 예매 수수료
순지출       = 실제 구매금액 + MD 합계 - 티켓 양도 금액
```

- **양도받음** : 양도자에게 지급한 금액이 그대로 실제 구매금액입니다.
- **예매수수료 면제 쿠폰** : 예매 수수료를 0원으로 계산합니다. (쿠폰 합계에는 들어가지 않습니다)
- 할인액은 원 단위에서 반올림합니다.
- 쿠폰이 너무 커서 실제 구매금액이 마이너스가 되면 **0원**으로 처리하고 안내 문구를 보여줍니다.

**예시** (정가 170,000원 / 할인 10% / 쿠폰 10,000원 + 3,000원 / 수수료 2,000원 / MD 포스터 15,000원)

```
실제 구매금액 = 170,000 - 17,000 - 13,000 + 2,000 = 142,000원
순지출       = 142,000 + 15,000 - 0             = 157,000원
```

**양도함 예시** (정가 150,000원 / 수수료 면제 쿠폰 / 양도 금액 140,000원 / MD 응원봉 30,000원)

```
실제 구매금액 = 150,000 - 0 - 0 + 0   = 150,000원
순지출       = 150,000 + 30,000 - 140,000 = 40,000원
```

### 통계 (월별 · 공연별 · 순위)

```
총 티켓 지출 = 실제 구매금액의 합 - 티켓 양도 금액의 합
총 MD 지출   = MD 금액의 합
총 순지출    = 총 티켓 지출 + 총 MD 지출
회당 평균    = 총 순지출 ÷ 관람 횟수   (원 단위 반올림, 관람 횟수가 0 이면 계산하지 않음)
```

## 8. 데이터 저장

- 입력한 내용은 실행한 폴더의 **`data.json`** 에 저장됩니다.
- 프로그램을 켤 때 한 번 불러오고, **등록 · 수정 · 삭제를 할 때마다 바로 저장**합니다. 따로 저장 메뉴는 없습니다.
- 저장에 실패하면 `data.json 에 저장하지 못했습니다` 라고 알려줍니다. 이때 프로그램을 끄면 방금 바꾼 내용은 사라집니다.
- `data.json` 이 없으면 빈 파일을 새로 만듭니다.
- `data.json` 이 깨져서 읽을 수 없으면, 새 파일로 시작할지 물어봅니다.
  - `y` : 원래 파일을 **`data_backup.json`** 으로 이름을 바꿔 남겨두고 빈 데이터로 시작합니다.
  - `n` : 파일을 건드리지 않고 프로그램을 끝냅니다.
- 다른 컴퓨터로 옮길 때는 프로그램 폴더와 `data.json` 을 같이 복사하면 됩니다.

## 9. 파일 구성

| 파일 | 역할 |
|---|---|
| `main.py` | 프로그램 시작 · 종료. 시작할 때 `data.json` 을 한 번 불러옴. 한글 입력용 `readline` 불러오기 |
| `cli.py` | 메뉴와 표 출력, 입력 받기, 삭제 · 저장 확인 (y/n) |
| `service.py` | 공연 · 관람 기록 등록 / 수정 / 삭제, 검색, 저장 전 2차 검증, 통계 요청 전달 |
| `expense.py` | 실제 구매금액, MD 합계, 순지출 계산 |
| `statistics.py` | 월별 통계, 공연별 분석, 순위 계산 |
| `repository.py` | `data.json` 불러오기 · 저장 |
| `input_utils.py` | 숫자 · 날짜 · 필수값 검사 |
| `test_calc.py` | 자체 테스트 |

파일 사이의 호출 관계 (위에서 아래로 한 방향):

```
main.py ──> cli.py ──> service.py ──┬──> expense.py
               │           │         ├──> statistics.py
               │           │         └──> repository.py ──> data.json
               └───────────┴──────────────> input_utils.py
```

## 11. 문제가 생겼을 때

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| `python3: command not found` | 파이썬이 없거나 명령어 이름이 다름 | 파이썬 3.11 이상 설치. Windows 는 `python main.py` |
| PyCharm 에서 `Cannot run program ... .venv/bin/python` | PyCharm 에 지정된 가상환경이 없음 | 프로젝트 폴더에서 `python3 -m venv .venv` 로 가상환경을 만들거나, PyCharm 설정에서 인터프리터를 다시 고르기 |
| **한글이 한 글자씩 밀리거나 Enter 를 두 번 눌러야 넘어감** | PyCharm 실행 창에서 한글 입력기가 글자 조합을 늦게 넘김 | PyCharm 의 **Emulate terminal in output console** 켜기, 또는 터미널에서 실행 |
| 화면이 안 지워지고 `[H[2J[3J` 같은 글자가 보임 | 진짜 터미널이 아닌 창에서 실행 | 위와 같음 |
| 한글을 백스페이스로 지우면 빈칸이 생기거나 글자가 어긋나게 들어감 | `readline` 없이 입력을 받는 환경. macOS 는 백스페이스를 한글 한 글자(3바이트)가 아니라 1바이트씩 지움 | 터미널에서 실행하면 `readline` 이 자동으로 켜져서 한 글자씩 지워짐. `python3 -c "import readline"` 이 오류 없이 끝나는지 확인 |
| `입력에 깨진 글자가 섞여 있어서 지웠습니다` | 한글을 쓰다가 백스페이스로 지울 때 글자 일부만 지워져서 깨진 글자가 남음 (주로 PyCharm 실행 창처럼 `readline` 이 안 되는 곳) | 프로그램이 자동으로 지우고 저장합니다. `->` 뒤에 보이는 값이 맞는지 확인하고, 틀리면 수정 메뉴에서 고치기 |
| 목록 표에서 글자 끝이 `..` 으로 나옴 | 표 칸보다 길어서 줄여서 보여준 것 | 저장된 값은 전부 들어 있음. **상세 보기**에서 전체 확인 |
| `data.json 파일을 읽을 수 없습니다` | `data.json` 이 깨졌거나 직접 고치다가 형식이 틀림 | `y` 를 고르면 원래 파일은 `data_backup.json` 으로 남고 새로 시작. 백업 파일은 메모장 등으로 열어서 필요한 내용을 확인 |
| `data.json 에 저장하지 못했습니다` | 디스크 공간 부족, 파일 권한 없음, 다른 프로그램이 파일을 잡고 있음 | 원인을 해결한 뒤 같은 작업을 다시 하기. 끄기 전에 해결해야 입력한 내용이 남음 |
| 껐다 켰더니 기록이 없음 | 다른 폴더에서 실행해서 그 폴더에 새 `data.json` 이 생김 | 프로그램 폴더로 `cd` 한 뒤 실행 |
| 표 줄이 삐뚤어짐 | 터미널 폭이 좁거나 한글 폭을 다르게 쓰는 글꼴 | 터미널 창을 70칸 이상으로 넓히기, 고정폭 글꼴 사용 |
